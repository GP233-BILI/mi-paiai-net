# 配置教程

所有配置都可以在网页控制台完成。运行中点击“保存配置”后，mi-paiai 会热重载音箱 Worker；Docker 容器不会重启。

## 1. 控制台分类

| 页面 | 用途 |
|---|---|
| 概览 | 服务状态、音箱在线情况、配置摘要、最近日志 |
| 音箱管理 | 小米账号、设备、模型、思考等级、多音箱隔离 |
| AI 服务 | 厂商、Base URL、API Key、模型目录与语音序号 |
| 对话行为 | 系统提示词和 AI 触发关键词 |
| 语音合成 | TTS Command 与火山引擎 TTS |
| 实时日志 | 按音箱和类型筛选，智能跟随最新日志 |

## 2. AI 接口

mi-paiai 使用 OpenAI 兼容接口。最重要的字段：

- **AI 厂商**：选择预设，或使用“自定义”。
- **API Base URL**：一般以 `/v1` 结尾。
- **API Key**：保存后不会再次回传到浏览器；输入框留空会保留原值。
- **默认模型**：新音箱默认使用的模型。

### 内置预设

- OpenAI、Anthropic、Gemini、xAI Grok、Mistral、Groq；
- DeepSeek、智谱 GLM、通义千问、Kimi、MiniMax、豆包、混元；
- New API、One API、OpenRouter、OpenCode、AiHubMix；
- Ollama、LM Studio、vLLM、SGLang、Azure OpenAI；
- 任意自定义 OpenAI 兼容服务。

服务商地址可能变化，选择预设后仍可手动修改。

## 3. 获取和排列模型

1. 填写 Base URL 和 API Key。
2. 点击“从上游获取模型”。
3. 使用搜索框寻找模型。
4. 单击模型：把它设为当前默认模型。
5. Ctrl / ⌘ + 单击：按点击顺序多选。
6. 手机端：开启“多选排序”，再依次点选模型。
7. 点击“按选择顺序置顶”。
8. 也可使用 ↑ / ↓ 微调前 20 个语音序号。

例如列表前 3 项为：

```text
1  gpt-4o-mini
2  deepseek-chat
3  gemini-flash
```

就可以说“换模型 2”切换到 `deepseek-chat`。

## 4. 添加多台音箱

每台音箱需要独立填写：

- `显示名称`：仅用于控制台和日志；
- `小米 ID`：小米账号数字 ID；
- `密码` 或 `PassToken`；
- `设备名称`：用于匹配账号下的具体设备；
- `当前模型`；
- `思考等级`；
- `允许语音切换`。

建议不同音箱使用不同的小米账号。每台音箱会启动独立 Node.js 子进程，并使用独立工作目录，因此令牌缓存和对话历史不会共享。

## 5. 思考等级

| 控制台 | 请求参数 |
|---|---|
| 默认 | 不发送 `reasoning_effort` |
| 最低 | `minimal` |
| 低 | `low` |
| 中 | `medium` |
| 高 | `high` |

并非所有模型都支持该参数。接口返回 HTTP 400 时，请切回“默认”。

## 6. 对话行为

### 系统提示词

定义助手人设。建议保持简洁，音箱播报更自然。

### 唤醒关键词

每行一个，最多 20 个。普通对话只有在文本包含关键词时才请求 AI；模型和思考等级的语音控制不受关键词限制。

## 7. 实时日志

- 完整日志按时间从旧到新排列，最新消息在底部。
- “跟随最新”默认开启。
- 手动上滚查看历史时自动暂停跟随。
- 有新日志时会显示“回到最新”。
- 设置会保存在浏览器本地。
- 概览页的最近日志保持“最新在最上”。

## 8. TTS

默认使用小爱音箱原生播放。某些机型无声音时，可开启 `TTS Command`。

火山引擎 TTS 需要：

- App ID；
- Access Token；
- 默认音色；
- 音箱可访问的 mi-paiai 地址。

不要把 TTS Token 写进公开仓库。

## 9. 配置文件

网页最终写入：

```text
/app/config/default.yaml
```

宿主机位置由 Docker volume 决定。写入使用临时文件 + 原子重命名，权限为 `0600`。
