# 语音控制教程

在“音箱管理”中为对应音箱开启“语音切换”后，以下命令会由 mi-paiai 直接处理，不会发送给大模型。

## 模型切换

### 按序号

```text
小爱同学，换模型 2
小爱同学，切换到第三个模型
小爱同学，换成第十个模型
```

序号来自“AI 服务 → 语音切换顺序”。

### 按模型名称

```text
小爱同学，切换模型 deepseek-chat
小爱同学，使用 Gemini Flash 模型
小爱同学，换成 claude sonnet
```

匹配会忽略：

- 英文字母大小写；
- 空格；
- `-`、`_` 等分隔符；
- 结尾的“模型”二字。

如果模糊名称同时匹配多个模型，系统不会猜测，以免切错；请说更完整的名称或使用序号。

### 查询模型

```text
小爱同学，当前模型
小爱同学，有哪些模型
```

“有哪些模型”会读出前 10 个模型及其序号。

## 思考等级

```text
小爱同学，切换思考等级 高
小爱同学，设置思考等级为最低
小爱同学，开启深度思考
小爱同学，关闭思考
小爱同学，当前思考等级
```

| 说法示例 | 等级 |
|---|---|
| 默认、关闭、取消 | `default` |
| 最低、快速、最小 | `minimal` |
| 低 | `low` |
| 中、标准 | `medium` |
| 高、最高、深度 | `high` |

## 多音箱行为

语音命令只改变接收到命令的那台音箱：

- 客厅音箱切到模型 2，不会改变书房音箱；
- 每台音箱的模型与思考等级独立持久化；
- 每台音箱拥有自己的对话历史和小米登录缓存。

## 没有响应

依次检查：

1. 对应音箱是否开启“启用”；
2. 是否开启“语音切换”；
3. 模型是否存在于模型目录；
4. 实时日志是否出现该句话；
5. 设备名称是否匹配正确音箱。
